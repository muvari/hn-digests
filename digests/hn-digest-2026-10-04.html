6 AI & ML

369 points · 276 comments · liao.gg

Kevin Liao argues that today's AI-agent "memory" plugins — which embed conversation snippets into a vector database and retrieve the top matches by similarity — solve the wrong problem, since similarity search can't tell what's correct, current, or missing. What the comments said

  • A popular counterpoint: agents already have perfect recall of the current session, so the real unsolved problem is memory across sessions, not search within one.
  • Multiple commenters described their own pre-existing systems — ADRs, principle files, decision logs — suggesting this is a convergently rediscovered idea rather than a wholly novel one.
  • Others raised the staleness problem: how does an agent know when a decision written down months ago no longer applies to the current code?

30 Systems

Page Table Memory Consumption

72 points · 11 comments · frn.sh

Fernando Simões traces a recurring, decades-old kernel problem: when many processes map the same large shared-memory region, each process needs its own page table entries for it, so page-table memory scales with the number of mappers, not just the data size — causing real production outages at Oracle (shared-memory SGA), Postgres, and ClickHouse deployments, several of which were fixed or mitigated using huge pages.

What the comments said
