180 points · 38 comments · sofiabelen.github.io

A deep-dive blog post dissects how Rust's dyn Trait dynamic dispatch works in memory, contrasting it with C++ virtual functions and CRTP-based static dispatch.   • A note that the article's "Object Safety" terminology is outdated — Rust now calls this "dyn compatibility."
  • Strong praise for the writing quality, alongside a joke that a post titled "Visualizing" contains no diagrams.

  • Compliments on the code quality, describing it as a sophisticated context-mixing entropy coder layered on existing codecs; a note that the author also wrote the bzip3 compressor.
